For texture sets, 1K/2K JPG colour, normal and roughness maps are sufficient; the Blender project is unnecessary. HDR lighting needs a 1K/2K `.hdr` or `.exr`. Weapon assets need an embedded-texture GLB or a smaller ZIP containing the Blender file and its textures. Accessible GitHub download links are another option. The HTML builder embeds all final assets for offline use.
