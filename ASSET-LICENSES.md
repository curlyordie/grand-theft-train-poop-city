## Police character and retained source references

The police character is **Soldier/Vanguard**, a textured skinned character and Idle/Walk animations obtained from [Three.js r180's Soldier.glb example](https://github.com/mrdoob/three.js/blob/r180/examples/models/gltf/Soldier.glb), originally supplied through Adobe Mixamo. Adaptations: model scale, orientation, removed visor, clothing/ginger vertex tints, animation speed and game attachments. Adobe Mixamo supplies characters and animations royalty-free for use within games; the model is included as part of this game, not offered as a separate asset product. See [Adobe's Mixamo FAQ](https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html). The MIT notice above covers the Three.js loader and example code; it is not a claim that Adobe's underlying art copyright is MIT-licensed.

CesiumMan is retained as an unused development reference in the source tree. It is not loaded by the final game. Its attribution above applies to that file.

**Michelle** is a retained development reference, formerly the second resident mesh, obtained from [Three.js r180's Michelle.glb example](https://github.com/mrdoob/three.js/blob/r180/examples/models/gltf/Michelle.glb). It uses its native posed skeleton with added procedural leg movement. The same Three.js/Mixamo source and game-use attribution above applies. It is included as part of the game, not supplied as an independent asset product.

## User-selected player replacement

Converted to `src/assets/boss.glb`, preserving the character textures, with game scale/orientation adjustments and the uploaded Mixamo actions described below. Adobe Mixamo's [FAQ](https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html) permits royalty-free character use within games. It replaces the previous Soldier mesh for the player only. **Remy**: supplied by the user as `Remy.fbx.zip`, downloaded by them from Adobe Mixamo. Converted to `src/assets/remy.glb` with its embedded diffuse/normal textures and subsequently uploaded Mixamo actions. **Remy face retexture**: supplied by the user as `Remy_Face_Texture_Final_Package.zip`. The replacement `Remy_Face_Texture_Final.png` is applied to Remy's Bodymat diffuse map at its original 2048 × 2048 resolution, encoded as WebP for the embedded game. The package supplies no additional creator credit or licence statement. All other model maps, geometry, UVs, skeleton and animations are preserved.

## User-selected 2K surface materials

- **Asphalt 02**, [Poly Haven source](https://polyhaven.com/a/asphalt_02), CC0: roads and broken road patches.
- **Worn Asphalt**, [Poly Haven source](https://polyhaven.com/a/worn_asphalt), CC0: pavement slabs.
- **Worn Corrugated Iron**, [Poly Haven source](https://polyhaven.com/a/worn_corrugated_iron), CC0: corrugated roofs and metal patches.

Supplied by the user as the respective 2K Blender ZIPs. Colour, OpenGL normal and roughness maps retain 2048 × 2048 resolution and are converted to high-quality WebP for the browser. EXR data maps are converted without a colour/gamma transform; only colour maps use sRGB in-game. Geometry displacement files are not applied. Texture tiling follows world dimensions for roads/pavements and the local roof orientation for metal sheets. All maps are embedded in the standalone HTML.

## User-supplied Mixamo animations

Uploaded Mixamo clips are retargeted to The Boss and Remy and packed as compressed animation data in `src/assets/motions.bin`. Adobe Mixamo's royalty-free game-use FAQ above applies; the clips are incorporated into this game rather than supplied as a standalone animation product. Adaptations: skeleton proportions, removed horizontal root motion, limited vertical body bob, playback timing and blending to match physics, attacks and reload durations. The latest Punching (1) replaces the earlier Punching file. Both Start Walking uploads have their requested separate action mappings.

The game uses the uploaded walking, starting, jogging, backward jogging, strafing, jumping/landing, stopping, direction-changing, rifle walking/turning/firing, punching, dagger-stab, reloading, pickup and driving clips. Melee attack slots share Double Dagger Stab as requested. Native Soldier idle/walk clips remain for police. Driving skeleton envelopes are fitted to each enclosed vehicle before rendering, keeping character animation outside the vehicle physics calculation.

## User-supplied vehicles

Mercedes-Benz GLS 580, Koenigsegg Agera, Car Upload (displayed as Old Town SUV) and the motorbike were supplied by the user in three ZIPs and a RAR. These archives contain Blender scene sources but no separate creator credit or licence document. Included here as part of the game. Adaptations: scene/model selection, removal of showcase platforms/road, baked static poses, forward orientation, detailed game display meshes, proportional sizing, fitted collision/cabin bounds, paint variations and wheel pivots. The Agera's nine disconnected outlier vertices are omitted. Dashboard maps are embedded as WebP; absent linked source images are replaced by shader colours rather than downloaded from an unknown source. The supplied three cars and bike are bundled locally. Existing rickshaws remain the project's procedural model.

Vehicle geometry, including the retained ToyCar, is packed with Meshopt. Position error is bounded relative to the model size, staying below a millimetre at game scale. The original ToyCar's material maps remain unchanged. The Meshopt decoder is by Arseny Kapoulkine, licensed under MIT; its copyright/permission notice is embedded in the standalone HTML.
